# Evidence & Confidentiality

This portfolio case study is based on the surviving ComBox project package, application screens and first-hand project context.

## Published evidence

The repository uses five selected screenshots:

- dashboard;
- stock management;
- sales / delivery notes;
- product movement history;
- commercial journal and reporting.

The visible customer/supplier names and commercial values in these screenshots were reviewed and approved for public use.

## Private project material

The following material remains private:

- native WINDEV project files;
- HFSQL database/data files;
- project backups;
- connection or credential metadata;
- internal filesystem paths;
- activation or license serial information.

The About/activation screen is intentionally excluded because it contains license/serial information.

The public repository is therefore a portfolio case study of the product's design and functional breadth, not a distribution of the original commercial source project.
