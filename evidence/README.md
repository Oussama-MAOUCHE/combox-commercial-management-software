# Evidence & Confidentiality

## Evidence reviewed

This case study is grounded in surviving professional project material and first-hand project context.

Reviewed evidence includes:

- ComBox WINDEV project package;
- application screenshots from multiple modules;
- stock and product screens;
- sales/delivery-document screens;
- reception/purchasing screens;
- product-movement screens;
- reporting/journal screens;
- product About/branding screen;
- confirmed HFSQL deployment context;
- confirmed commercial use and team-development context.

## Approved public screenshots

The first public version uses six screenshots:

1. dashboard;
2. stock management;
3. delivery notes / sales documents;
4. reception / purchasing documents;
5. product movement history;
6. commercial journal/reporting.

The user authorizes publication of the customer/supplier names and commercial values visible in these selected screenshots.

## Material kept private

The repository does not publish:

- raw WINDEV project files;
- raw HFSQL data/database files;
- project backups;
- connection or credential metadata;
- internal filesystem paths;
- activation/license serial values;
- unreviewed configuration secrets.

The About/activation screenshot is intentionally not published because it includes license/serial information.

## Evidence rule

Public claims must remain traceable to reviewed project material or confirmed first-hand facts.

The case study demonstrates product breadth and real commercial use without inflating the application into a broader ERP/accounting/CRM scope.
